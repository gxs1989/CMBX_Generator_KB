## Web Workflows

- Batch Raw Data Export: select CMBX, sequence, injection, and channel; preview
  and export decoded raw points.
- Chromatograms & Integration: plot selected traces, zoom/pan, apply one
  integration parameter set, and review peak/baseline evidence.
- Direct CM Formula Results: discover Direct CM formula objects and evaluate them
  across filtered CMBX contexts.
- External Report Engine: execute a task-specific Report MD against one or more
  completed CMBX packages.

## Key Contracts

- Formula implementations are evidence-backed subsets, not a claim that every CM
  formula or FormulaOne function is executable externally.
- FormulaOne workbook inventory can be decoded separately from Direct CM formula
  evaluation.
- Raw signal, audit, RetTime, and metadata provenance must remain visible in
  exported results.
